0x00000010 CXnIp::IpIsSecurityBypassed CXnIp::IpIsPeerEncryptionDisabled
0x00000020 hdd presence 1=present
0x00000040
0x00000080 if set bugcheck is fatal or kd is enabled
0x00000100 if set bugcheck is breakpoint
0x00000200 if not 0 on devkit, causes a twi in XamInitXenonButton
0x00000400 media restriction
0x00000800 vd related
0x00001000 staging mode on (XamSetStaging), reads argon errors in xam	HalGetNotedArgonErrors
0x00002000 power mode related
0x00004000 xenon button disabled
0x00010000 1GB ram (pixdump partition related)
0x00020000 mmcx (nand mu) 1= present (pci bridge > 0x70 and value at 0x7FEAC0FC/corona mmc controller reg? is nonzero)
0x02000000 1 if devkit, otherwise testkit/retail
0xF0000000 system type (0=xenon, 1=zephyr, 2=falcon, 3=jasper, 4=trinity, 5=corona, 6=winchester, ?7?=ridgeway)

0x02000000 = 1 = devkit
0x00010000   = 4 = 1G RAM
